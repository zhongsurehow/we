# How to Run the Game Prototype

To run the game, please execute the following command from the root directory of the repository:

```bash
python3 game_prototype/main.py
```

The game is interactive and will prompt you for actions at the `Action>` prompt. The available commands are:
- `play <card_index> <zone_name>` (e.g., `play 0 乾`)
- `move <zone_name>` (e.g., `move 人`)
- `task <task_index>` (e.g., `task 1`)
- `pass`
- `exit`
